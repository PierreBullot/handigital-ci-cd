Un cas de test par ligne.

| N° | Action                      | Résultat attendu                  | Vérifié par     |
|----|-----------------------------|-----------------------------------|-----------------|
| 1  | Ajouter la tâche "lire"     | La tâche "lire" est dans la liste | Test automatisé |
| 2  | Supprimer une tâche         | La liste est vide                 | Test automatisé |
| 3  | Compter le nombre de tâches | Le résultat est 0                 | Test automatisé |
| 4  | Vérifier l'apparence        | La liste a l'apparence souhaitée  | A la main       |
| 5  | Ajouter une tâche           | La nouvelle tâche est affichée    | A la main       |
